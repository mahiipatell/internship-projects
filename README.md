# Software Development Internship Projects

This repository contains a collection of full-stack web applications developed during my Software Development Internship. The projects cover authentication, CRUD applications, database design, REST APIs, third-party API integration, role-based access control, analytics dashboards, financial management, file processing, reporting, and modern frontend development using React, Express, PostgreSQL, Prisma, Firebase, and TypeScript.

## 🚀 Getting Started

To run any project locally:

### 1. Clone the repository

```bash
git clone <your-repository-url>
```

### 2. Navigate to the repository

```bash
cd Intership-Projects
```

### 3. Open the required project

For example:

```bash
cd 07-Student-Management-System
```

### 4. Follow the project-specific README

Each project may have different environment variables, database setup, API keys, and installation commands.

Refer to the README inside the respective project folder for complete setup instructions.

---

## 📌 Important Notes

* Environment files containing secrets are excluded from version control.
* Each project provides an `.env.example` file where applicable.
* API keys and database credentials must be configured locally before running projects that require them.
* Dependencies should be installed separately for frontend and backend applications where applicable.
* Some projects require PostgreSQL and database migrations before running.
